# HTML 可视化编辑器

用接近幻灯片的操作方式调整网页文字、图片与布局。提供独立网页版和本地文件导入版。

## 快速开始

- 独立网页版：直接用现代浏览器打开仓库根目录的 `index.html`。
- 本地工程：进入 `local/` 运行 `npm start`，打开 `http://127.0.0.1:4173`。本地服务适用于可信文件和回环访问。

## 使用示例

新建一个包含标题、正文和图片的 HTML，导入后选择图片，拖动位置，使用裁剪框调整取景。完成后导出自包含 HTML。独立网页版提供 PNG 和 PPTX 导出，PPTX 以页面图片呈现。某些导出流程依赖浏览器能力以及页面素材是否允许跨域读取。

## 代码结构

- `index.html` 是可单独分发的网页版。
- `local/` 包含本机版界面、Node.js 服务和用于回归的测试页面。
- `third-party-licenses/` 保存独立 HTML 内嵌组件的许可证。
